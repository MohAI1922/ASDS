Six-Layer Variational Architecture

Layer 1 · MS-AVP
Adaptive Weak Form & Hermite EIV

Wavelet-MAD noise estimation, curvature-optimal C⁴ bump windows, and exact Hermite/Wick variance debiasing for ODEs & 2D PDEs.

Layer 2 · VIFC
Differential Causality + Faithfulness Guard

State-to-rate graph via WF-cHSIC block knockoffs, partial CCM, and RBF Dyn-ICP—immune to cyclic feedback and conservation collinearity.

Layer 3 · W-LIND
Model-Free Conservation & Reynolds

Recovers invariants before knowing f(x) via zero-derivative linear nullspace with Univariate Exclusion and Reynolds equivariant pruning.

Layer 4 · EVG-HE
Equivariant Hybrid Symbolic Evolution

Tiered sparse projection + KKT conservation, TLS-SVD implicit weak rational solver, residual-guided GP+VarPro, and K_eff-MDL snapping.

Layer 5 · PAFE & SLR
Active Falsification & Drift Regeneration

Selects maximally discriminating experimental initial conditions and detects online SIR→SIRS regime shifts via Dual-Channel CUSUM.

Layer 6 · ASDS-Verify
SymPy & Lean 4 Formal Certification

Analytically verifies conservation, equivariance, equilibria, and divergence, exporting sorry-free Lean 4 proof certificates.

Quick Start: Python SDK, CLI & Standalone Desktop GUI

# 1. Clone & install (Python 3.11+)
git clone https://github.com/MohAI1922/ASDS.git
cd ASDS
pip install -e ".[dev,benchmarks]"

# 2. Launch standalone native Desktop GUI Workbench (KaTeX + 2D/3D Plotly + CSV + PDE + Lean 4)
asds-omega gui

# 3. Or run headless browser server / CLI discovery / 5-seed benchmarks
asds-omega serve --host 127.0.0.1 --port 8000
asds-omega discover --dataset lorenz --noise 0.05 --seed 42
asds-omega benchmark --seed 42 --n-seeds 5 --out results
